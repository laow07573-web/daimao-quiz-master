05

问答

FAQ
Q.01 收费吗？

完全免费，无账号无会员无广告。

Q.02 数据存在哪？

全在你自己设备（SQLite）；同步也只在局域网设备之间。

Q.03 要 API Key 吗？

导入 DOCX/PDF 与 AI 讲解要（自己的 Key，OpenAI 兼容）；JSON 导入、刷题判分、统计、复习不要。

Q.04 Windows 提示“已保护你的电脑”？

更多信息 → 仍要运行。

Q.05 怎么校验文件？

PowerShell 里执行，与 SHA256SUMS.txt 比对：

Get-FileHash .\MaoJuan-… -Algorithm SHA256
Q.06 系统要求？

Android 6.0+（含）/ Windows 10 64 位。
