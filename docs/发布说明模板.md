# 发布说明模板

> 使用方式：每次发版时复制本模板填写，作为 GitHub Release 的说明正文。
> 同时把对应条目写进仓库根目录的 `CHANGELOG.md`，两者内容保持一致。
>
> 本地发版（`tools/publish_release.ps1`）会自动生成一份与本模板结构一致的说明；
> 使用 CI 发版（推送 `v*` tag）时，`.github/workflows/release.yml` 也会自动生成。
> 本模板主要用于需要手写说明的场合（例如重要版本的额外说明）。
