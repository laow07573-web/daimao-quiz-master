# 猫卷 · 部署与分发指南

本文说明**推广页上线**与**安装包国内分发**的完整做法，以及**发新版时的一条命令流程**。

## 零、当前已上线（GitHub Pages）

**网址：https://laow07573-web.github.io/daimao-quiz-master/**

已用你现有的 GitHub 账号开通，**无需任何新注册**，下载链接指向 Releases 的真实文件
（版本号由 `tools/publish_release.ps1` 自动同步，不手工维护）。
重新部署只需一条命令：

```powershell

```

## 一、最终架构

**不需要网盘。** GitHub Pages 单文件上限是 100MB（Cloudflare Pages 才是 25MB），
所以四个文件全部随页面同源分发：

```
用户访问 https://laow07573-web.github.io/daimao-quiz-master/
   │   index.html / 404.html / favicon.png / assets/logo.png
   └─ download/
        ├─ MaoJuan-v<版本>-android-arm64.apk       约 20 MB  ← 推荐（2017 年后多数手机）
        ├─ MaoJuan-v<版本>-android-universal.apk   约 35 MB  ← 通用版（含全部 CPU 架构）
        ├─ MaoJuan-v<版本>-windows-setup.exe       Windows 安装包
        └─ MaoJuan-v<版本>-windows-portable.zip    Windows 绿色版

别的下载入口（备用）：GitHub Releases
```

> `<版本>` 随发版变化；这四个文件名与 index.html 里的链接由
> `tools/publish_release.ps1` 自动同步，不需要手工维护。

**好处**：同源直链，点一下就下、无跳转页、无广告、不断链，也不需要注册任何网盘。

### 什么情况下才需要网盘

只有当 APK 超过 **100MB** 时（GitHub Pages 限制），才需要改用网盘或对象存储。
现在 34.7MB 的通用版都放得下，所以网盘不是必需的。

### 关于 Android 精简版（20.4MB）

`--target-platform android-arm64` 构建出的包只含 arm64 架构，体积从 34.7MB 降到 20.4MB。
2017 年后的绝大多数手机都是 arm64，推荐优先下这个；不确定机型就用「通用版 APK」。

## 二、首次上线

### 步骤 1：注册 Cloudflare（约 3 分钟，免费，不绑卡）

1. 打开 https://dash.cloudflare.com/sign-up
2. 填邮箱 + 密码，收到验证邮件点确认
3. 登录后**不需要**添加域名，直接进下一步

### 步骤 2：创建 API Token（约 2 分钟）

1. 右上角头像 → **My Profile** → 左侧 **API Tokens** → **Create Token**
2. 拉到底选 **Create Custom Token**
3. 按下面填：

| 字段 | 值 |
|---|---|
| Token name | `maojuan-deploy` |
| Permissions | `Account` → `Cloudflare Pages` → `Edit` |
| Account Resources | `Include` → 你的账号 |

4. **Continue to summary → Create Token**
5. 复制 Token（**只显示一次**）

同时记下 **Account ID**：Cloudflare 首页右侧栏，或 URL 里 `dash.cloudflare.com/<这段就是 Account ID>`

### 步骤 3：部署

```powershell
cd D:\dev\flashcard_app
$env:CLOUDFLARE_API_TOKEN  = "<步骤2复制的 Token>"
$env:CLOUDFLARE_ACCOUNT_ID = "<你的 Account ID>"

powershell -ExecutionPolicy Bypass -File tools\deploy_promo.ps1
```

脚本会：暂存文件 → 检查 25MB 限制 → 用 wrangler 上传 → 输出网址。

首次运行若提示 `wrangler not found`，脚本会自动安装（走 npmmirror 国内源）。

**如果 wrangler 装不上**（国内网络问题），改用面板手动上传：

```powershell
powershell -ExecutionPolicy Bypass -File tools\deploy_promo.ps1 -Stage
```

然后打开 Cloudflare 面板 → **Workers & Pages** → **Create** → **Pages** → **Upload assets**，
把 `build\promo_deploy` 整个文件夹拖进去。

### 步骤 4：撤销 Token（重要）

部署成功后回到 **My Profile → API Tokens**，找到 `maojuan-deploy` 点 **Delete**。
以后要再部署，重新建一个即可（步骤 2 只要 2 分钟）。

### 步骤 5（一般不需要）：APK 传网盘

**当前不需要这一步** —— APK 只有 20.4 / 34.7MB，直接放在 GitHub Pages 上同源分发。

只有以后 APK 超过 100MB 时才需要：

1. 注册 **123 云盘** https://www.123pan.com 或 **蓝奏云** https://www.lanzou.com（都要手机号）
2. 上传 `dist\MaoJuan-v<版本>-android-*.apk`，**不要设提取码**
3. 把分享链接填进 `promo/index.html` 配置块的 `android` 字段
4. 重新部署：`powershell -ExecutionPolicy Bypass -File tools\deploy_pages.ps1`

## 三、发新版（一条命令）

```powershell
$env:CLOUDFLARE_API_TOKEN  = "<token>"
$env:CLOUDFLARE_ACCOUNT_ID = "<account id>"
$env:GH_TOKEN              = "<fine-grained PAT，权限 Contents: Read/Write>"

# 版本号取自 pubspec.yaml（唯一来源）；也可以显式传 -Version，但必须与之一致
powershell -ExecutionPolicy Bypass -File tools\publish_release.ps1
```

> **版本号怎么改**：只改 `pubspec.yaml` 的 `version:` 字段（形如 `1.29.0+21`），
> 然后跑上面的命令即可。应用内展示的版本号由脚本通过 `--dart-define` 注入，
> README 徽章是动态的，推广页版本号也会自动同步——**不需要改任何其他文件**。
> 忘了同步时 `test/version_single_source_test.dart` 会直接报红。

这条命令依次做 8 件事：

| # | 动作 | 失败即中止 |
|---|---|---|
| 1 | `flutter analyze` | 有 issue 就停 |
| 2 | `flutter test` | 测试红就停 |
| 3 | 构建 APK + Windows | 构建失败就停 |
| 4 | `verify_reference` 四维基线对照 | 非 PASS 就停 |
| 5 | 签名校验 | 证书非 `43a9e0a1…60fe` 就停 |
| 6 | 三个产物改名成 ASCII + 生成 sha256 | |
| 7 | 创建/更新 GitHub Release 并上传附件 | |
| 8 | 部署推广页到 Cloudflare Pages | |

**跑完后还剩两件手工事**（脚本会提醒）：

1. 把新的 APK 传网盘
2. 把网盘链接粘进 `window.MAOJUAN.android`，重跑一次 `deploy_promo.ps1`

> 为什么 APK 不能自动传网盘：蓝奏云/123 云盘没有面向个人免费用户的开放上传 API，
> 自动化会触发风控。这是国内网盘的通病，只能手工传一次。

常用参数：
- `-SkipTests`：跳过 analyze/test（仅在你刚跑过时用）
- `-SkipGithub`：只本地构建 + 部署网页
- `-SkipDeploy`：只构建 + 发 Release

## 四、日常只改网页

如果只改了推广页文案（不涉及 App），不需要走完整发布链：

```powershell
powershell -ExecutionPolicy Bypass -File tools\deploy_promo.ps1
```

脚本会从 `promo/index.html` 自动读出当前版本号，并从 `dist/` 找最新的 Windows 包一起上传。

> ⚠️ 注意：APK 是独立分发的，所以 `dist/` 里要有对应版本的 Windows 包，
> 否则页面上那两个 Windows 按钮会 404（脚本会警告，但不会中止）。

## 五、换平台怎么改

架构是 URL 驱动的，换地方只改两处：

| 换什么 | 改哪里 |
|---|---|
| 换网页托管（如改用腾讯云 EdgeOne Pages） | 只改部署方式；`promo/index.html` 里的相对路径不用动 |
| 换安装包托管（如改用自己的服务器） | 改 `window.MAOJUAN` 里的 `android` / `windowsSetup` / `windowsPortable` 三个地址 |

页面内所有链接都是**相对路径或配置块驱动**，没有硬编码的域名。

## 六、故障排查

| 现象 | 原因与处理 |
|---|---|
| 页面打开但下载按钮 404 | `dist/` 里没有对应版本的 Windows 包，或包名与配置块不一致。跑 `deploy_promo.ps1 -Stage` 看暂存目录里有没有 `download/` 下的文件 |
| `wrangler` 安装失败 | 用 `-Stage` 模式 + 面板手动拖拽上传 |
| 部署报权限错误 | Token 权限必须是 `Account → Cloudflare Pages → Edit`，且 `Account Resources` 要 Include 你的账号 |
| 国内打不开 `*.pages.dev` | Cloudflare 在国内是「多数可达但非保证」。备选：腾讯云 EdgeOne Pages（需实名，国内最快） |
| 网盘链接失效 | 页面同时保留了「备用下载 → GitHub Releases」，用户仍能下到；把新链接更新进配置块即可 |
| `verify_reference` FAIL | 若差异只是已审阅的新文案，先 `$env:REFCHECK_MERGE=1` 合并白名单再复验（详见 `tools/reference_check/`） |
| 签名校验失败 | **不要发布**。说明签名证书变了，会导致老用户无法覆盖升级、防篡改校验误报 |

## 八、安全约定（务必遵守）

### 签名变更史（2026-09 核对开发文件后确认）

项目经历过一次签名更换，时间线与影响如下（依据：开发包
`01_技术文档\签名文件_keystore\` 内两个 jks 的实测 + 各历史 APK 逐一验签）：

| 时期 | 版本 | 签名证书 | 指纹前缀 |
|---|---|---|---|
| 呆猫刷题宝（初版～2026-08-10） | v1.0 ～ v1.26.6 | **debug 调试证书**（口令是公开的 android） | `540320cd…` |
| 猫卷（2026-08-14 起） | v1.0.2 ～ 至今 | **正式证书**（口令仅存于离线保管处，不入库） | `43a9e0a1…` |

> ⚠️ **口令不写在仓库里**。签名口令与 `android/key.properties` 一律离线保管
> （见下方「密钥保管」）。此前本文档曾以明文记录过正式证书口令，已在历史重写中
> 清除；若你手上有旧克隆，请以本版本为准。

**当前在用的正式证书从未遗失**：开发包里的 `刷题宝_正式签名.jks` 与项目里的
`猫卷_正式签名.jks` 证书指纹完全一致（`43a9e0a1…`，别名 quiz，2026-06-24 创建）——
同一把钥匙换了个文件名，且开发包里留有备份。

三个结论：

1. **口令泄露已被轮换化解**：公开仓库历史里能翻到的旧口令 `quizmaster2024`
   是正式 jks 的**旧口令**（2026-06 曾泄露后当即更换，实测旧口令已打不开该 jks）。
2. **旧「呆猫刷题宝」用户无法直接覆盖升级**：新旧签名不同，Android 会拒绝安装。
   正确迁移路径：旧版「导出数据库备份」→ 卸载 → 装猫卷 →「导入备份」，
   老备份（schema v4/v5）会被逐步迁移到 v11，数据不丢。
3. **旧 debug 证书本就是公开钥匙**（Android 调试签名的口令是行业标准值），
   呆猫时期的包防伪能力有限，但该签名已弃用，不再影响任何现有用户。

> ⚠️ 开发包（`D:\work\刷题宝开发包`）里的 `签名文件_keystore\` 文件夹
> 含有在用签名证书与口令明文，**请勿外传或上传**。



- **签名文件与密钥永不入库**：`android/key.properties`、`**/*.jks`、`**/*.keystore` 已在 `.gitignore` 中
- **安装包不进 git**：`/dist/` 已忽略，统一走 Releases + 网盘（二进制进 git 会永久膨胀历史）
- **API Token 用完即删**：Cloudflare Token、GitHub PAT 都不要写进任何文件，只在终端里临时 `$env:`
- **发布前四项必过**：analyze 0 error/0 warning → test 全绿 → verify_reference PASS → 签名证书一致
