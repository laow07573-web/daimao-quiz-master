## 7. 刷题三模式（统一答题页 `lib/screens/quiz_screen.dart`）

| 功能 | 实现路径 |
|---|---|
| 抽题 | `lib/services/quiz_service.dart` `startQuiz(bankIds, mode, questionCount, noShuffle, persistSession)` → `DatabaseService.getQuestionsByBanks(..., random: !noShuffle)`（SQL `ORDER BY RANDOM()`）→ 数量截取（不足全用/超量 take N）→ 会话落库（`persistSession`） |
| 会话状态 | `AppState.startQuiz`（选库/数量 → 填充 `quizQuestions`）→ `QuizScreen` |
| 左右滑动切题 | `GestureDetector.onHorizontalDragEnd`（velocity ±300：左滑前进/右滑后退；刷题/背题需已答才前进，练习自由） |
| 末题左滑 | `_advanceQuestion` 检测 `isLastQuestion` → `_handleFinishSwipe()`：normal → `AppState.endSession()` 落统计 + pop 回首页（不经过小结页）；memorize → 直接 pop（零落库）；practice → 提交确认 |
| 单选/判断 | `_buildOptionsArea`/`_buildTrueFalseButtons` → `_handleSubmitAnswer` → `AppState.submitAnswer` → `QuizService.submitAnswer`（判定 `judgeAnswer`，判断题归一 √/×/T/F/正确/错误）→ 音效/震动 → 答对 600ms 自动跳题（题号比对防竞态） |
| 多选 | 勾选集合 +「确认提交 (已选 N 项)」 |
| 填空 | `_buildFillBlankInput`：按题面空数建输入框，回车跳下一空（FocusNode），最后一空提交；逐空 `judgeAnswer` 比对 |
| 名解/简答/问答 | `_buildTextAnswerInput` 文本输入 → 包含匹配判定（3 字精确相等豁免） |
| 重新作答 | 已答视图「重新作答」按钮 → `AppState.resetCurrentAnswer()` → 再提交走 `QuizService.resubmitAnswer`（**更新原记录不新增**，会话统计差量修正 + FSRS 补记） |
| 解析/追问 | `AppState.showAnalysis/regenerateAnalysis` → `AIService.getAnalysis`（缓存 `ai_cache`，失败串不缓存）/`askFollowUp`（mounted 检查） |
| 收藏 | 底部「错题本」按钮 → `AppState.toggleErrorBook`（`error_book` 表） |
| 练习模式 | `PracticeEntryScreen`（`lib/screens/practice_screen.dart` 选不限时/限时 15~120 或自定义）→ `QuizScreen(quizMode: practice, practiceTiming, practiceDurationMinutes)`：计时器 `_startPracticeTimer`（限时归零自动交卷先关弹窗）、答案收集 `_practiceAnswersMap`（零落库）、答题卡 `AnswerSheetWidget(showResult: false)`、底部「提交练习 (已答 X/N)」→ `_showSubmit` 确认 → `_submitPractice` 批量 `judgeAnswer` → `PracticeResultScreen`（正确率/错题回顾/全对彩蛋） |
| 背题模式 | 首页模式弹窗 → `QuizScreen(quizMode: memorize)`：`_buildMemorizeOptions` 只高亮正确选项；**零落库**（`startQuiz(persistSession: false)` + `skipFSRS` 进入置位退出复位 + 不调提交）；退出确认 |
| 退出确认 | PopScope → `_handleExit`：有作答 `endSession` / 无作答或练习背题 `abortSession`（`deleteSessionWithRecords`） |
