04 / FAQ

你可能想问。

没有 API Key，能用吗？

可以。导入 JSON 或内置示例题库后即可刷题，错题复习、批注和统计也无需 Key。DOCX 解析及 AI 讲解、追问需要联网与 Key。

支持哪些设备？

目前提供 Android 和 Windows 版本。手机与宽屏布局自适应，具体系统要求和安装文件请查看 Releases。

资料和学习记录会上传吗？

核心学习数据保存在设备本地。启用 AI 后，相关题目内容和请求认证信息会发送给你配置的服务商。局域网同步不经过云端。

支持 PDF 吗？

当前源码已包含 PDF 导入与配图能力，但更新日志仍列为待发布。下载安装时，请以所选版本的发布说明为准。

间隔复习如何安排？

使用 FSRS-5 简化实现，根据对错与作答耗时更新错题排期。它辅助安排复习，不承诺记忆率或考试结果。
