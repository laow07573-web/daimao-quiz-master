为什么做猫卷

备考工具的三个老问题，我们换了个解法

不是再做一个题库 App，而是把"学习资产的所有权"还给备考的人。

💸

订阅太贵，内容还锁死

主流考试平台按科目收费、年费数百到数千元，题库内容封闭；停止续费后，学习记录也带不走。

🔐

数据在别人服务器上

错题、笔记、学习轨迹全部锁在云端账号里。平台改规则、下架题库，你的努力就可能归零。

🧱

通用工具门槛太高

Anki 类工具制卡繁琐、缺考试题型和题目讲解；通用 AI 问答又没有错题管理和复习排期。

功能 01

丢一份文档进去，自动变成题库

不用一题一题手工录入。选择 DOCX 或 JSON 文件，猫卷自动识别题目、选项、答案与解析，生成可编辑的预览，确认后入库。

  • DOCX / JSON 双通道：Word 文档直接导入，也支持结构化 JSON 题库
  • AI 智能分块：长文档按题目边界切块，并发解析，不阻塞界面
  • 可视化校对：入库前逐题预览、编辑、删除，AI 打的知识点标签一并保留
  • 开放格式：题库可导出为标准 JSON，在同学之间自由流转
🧩 2000 字 / 块
⚡ 3 路并发
功能 02

题库是一个个独立的文件，随你管理

多题库并存、按需勾选、随时导出。每个题库的题量、正确率一目了然，重名会自动编号避免混淆。

  • 多库并存：考研、执医、规培各自成库，可单独或组合刷题
  • 导出即分享：一键导出 JSON 题库文件，同学导入即可用
  • 级联删除：删题库时相关题目、记录、批注一并清理，不留脏数据
📤 导出可分享
功能 03

三种模式，对应三种学习状态

正常刷题用来检测、练习模式用来模考、背题模式用来快速过题。同一套题目，三种节奏。

  • 正常刷题：答完即判，立刻看解析，答对自动跳下一题
  • 练习模式：限时（15–120 分钟）或不限时，答题卡漫游、统一交卷批改
  • 背题模式：高亮正确答案、不记统计，适合考前快速过一遍
  • 数量自由：10/20/30/50/80/100/全部/自定义
  • 断点续刷：中途退出进度保留，下次从首页继续，不丢一道题
🎯 答对自动跳题
⏸ 随时暂停续刷
功能 04

七种题型，每种都有对应的判定逻辑

不只是选择题。判断题、填空题、名词解释、简答题、问答题都能练，而且判分不是简单的字符串相等。

  • 单选 / 多选 / 判断：多选忽略顺序与分隔符；判断题自动归一化各种写法
  • 填空：按空拆分，逐空去标点比对
  • 名解 / 简答 / 问答：语义包含匹配，答到关键点即可
  • 重新作答：答错可重做，更新原记录而不新增，不污染刷题量
✅ 7 种题型
功能 05

不是给你答案，是教你题眼怎么破

每一道题的解析都按"题眼破题法"四步拆解，模拟一个老师在旁边讲题的过程。回答篇幅可选三档，关键词用颜色标出来。

  • 抓题眼，定性：第一句点出决定答案的关键数据或特征
  • 理逻辑，拆选项：讲透正确项推理，也说明错误项为什么错
  • 指坑点，防踩雷：精准指出最容易掉的陷阱与鉴别点
  • 给结论，划重点：一句口诀或大白话总结得分要点
  • 篇幅三档：简洁（≤150 字）/ 标准（≤300 字）/ 详细，设置里随时切换
  • 关键词高亮：答案绿、题眼蓝、避坑红，关键依据与易错否定词单独着色
  • 只看一次的钱：解析本地缓存，同一道题不重复消耗 Token
功能 06

看不懂？直接追问，像聊天一样

解析里哪一句没懂，就接着问。你的提问和 AI 的回答以对话气泡呈现，一问一答都留在题目旁边，下次打开还在。

  • 对话式交互：你的提问在右、AI 回复在左，一路聊到底
  • 按题保存：每道题的追问历史独立存储，换题不串、重启不丢
  • 富文本回复：支持加粗、列表、表格，长解析也读得清楚
  • 自动滚到底：内容变长时输入框跟随对话下移，不用手动找
为什么 PaCO₂ 升高就能定性为呼吸性酸中毒？
因为 PaCO₂ 是呼吸性指标：它由肺泡通气量决定，升高说明 CO₂ 排出受阻，属呼吸性因素；而 HCO₃⁻ 才是代谢性指标。
那代偿性升高怎么区分？
看 pH 与变化幅度：原发改变决定 pH 方向，代偿不会"矫枉过正"。
功能 07

错题不是收藏起来，是排好期再练

错题本内置 FSRS-5 间隔重复算法：按你的遗忘曲线计算每道错题的下次复习时间，到期的才出现，避免"反复刷已经会的"。

  • 自动排期：答完自动更新复习卡，不需要你手动设置"几天后再看"
  • 只显示到期：打开错题本，看到的都是此刻该复习的题
  • 反应时间参与评分：答得又快又对 → 判定为"简单"，间隔拉得更长
  • 知识点标签云：按知识点聚合错误，一眼看出薄弱章节，可一键专项复习
  • 薄弱诊断：结合统计数据生成学习建议

功能 08

刷题量、正确率、学习时长、连续打卡、错题分布……所有数据在本地实时计算，用图表讲清楚你的学习状态。

  • 近 30 天趋势：柱状题量 + 分层正确率双轴对照
  • 年度热力图：GitHub 贡献图样式，一整年 53 周 × 7 天，累计努力一眼可见
  • 正确率排行：按题库 / 按知识点两个维度，定位薄弱环节
  • 错题统计：总数、待复习、按题库分布与下次到期时间
  • 历史会话：每一轮练习都可回看，支持改判修正

功能 09

纸上怎么划重点，屏幕上就怎么划

直接在题目上圈关键词、划重点、写推导。笔迹按题目保存，切题、重启、换设备都不会丢。

  • 三种笔型：细笔 / 普通笔 / 荧光笔，支持压感调宽
  • 四色可选：红、蓝、绿、黑，颜色记忆偏好
  • 橡皮与选择：整笔擦除，或选中笔迹后平移 / 删除
  • 跨设备适配：手机、平板、桌面尺寸不同，笔迹位置保持一致
🖊 细笔 / 荧光笔 / 橡皮
功能 10

三套主题，每套都有深色版

长时间刷题，界面得顺眼。三套配色风格各配一套深色变体，可跟随系统自动切换。

  • 三种风格：清蓝（清爽专业）/ 松绿（护眼低疲劳）/ 墨黑（深色优先）
  • 深色模式：每套主题都有深色变体，跟随系统 / 手动切换
  • 全局统一：切换即时生效，所有页面同步换肤
  • 语义色体系：对错用固定的成功 / 危险色，任何主题下判断一致

  • 自适应断点：手机用底部导航，宽屏自动换成左侧竖向导航
  • 双栏布局：宽屏下题目与解析左右并排，减少滚动

  • 拖动即重排：桌面端改变窗口大小，布局实时响应

功能 12

同一个 Wi-Fi 下，手机和平板自动对上

没有云账号，也能多设备用。两台设备连同一个 Wi-Fi，自动发现彼此并交换题库与刷题进度，全程在局域网内完成。

  • 自动发现：同一 Wi-Fi 下设备自动出现在列表里，无需填 IP
  • 一次请求双向同步：互相交换快照并合并，双方都拿到对方数据
  • 智能合并：新增内容按全局 ID 去重，已有的按时间取新
  • 批注互不覆盖：各设备的笔迹共存，谁的批注都不丢
  • 不经过云：数据只在你的两台设备之间直接传输

功能 13

你的数据，真正属于你

没有账号体系，不采集个人信息。题库、错题、进度、批注全部存在本机 SQLite 数据库里，一键导出备份，换手机原样恢复。

  • 本地存储：全部数据在设备内，离线可用，卸载即彻底删除
  • 完整备份：一键导出数据库，换设备导入即可原样恢复
  • API Key 加密：密钥经 AES-256-GCM 加密，优先存入系统安全容器
  • BYOK 直连：AI 请求由你的 Key 直连模型服务商，项目方不接触你的数据
  • 防篡改：App 签名锁定，被二次打包会直接拒绝启动
