# 猫卷 · 功能展示页

面向推广的静态展示页：用动画分区展示 App 各项功能，每个功能区标明所用技术与实现方式。

## 打开方式

- **本地预览**：直接双击 `index.html`（部分浏览器对本地文件限制较严，建议用本地服务器）
- **本地服务器**：
  ```bash
  cd 项目根目录
  python -m http.server 8899
  # 浏览器打开 http://127.0.0.1:8899/promo/index.html
  ```

## 部署

整个 `promo/` 文件夹丢到任意静态托管即可（GitHub Pages / Gitee Pages / Vercel / 对象存储 / 自己的服务器）。
无需构建步骤，无外部依赖。

## 需要改的地方

1. **下载链接**：`index.html` 里搜 `id="dl-apk"` 与 `id="dl-win"`，把 `href` 改成实际下载地址（当前指向 `../dist/` 下的交付物）
2. **截图更新**：替换 `assets/` 下的图片（建议保持同名，或同步修改 HTML 里的 `assets/xxx.jpg`）
3. **文案**：正文直接改 `index.html`，无构建步骤

## 动画说明

- Hero 与「三种模式」的手机截图自动轮播（2.4–2.6s/张）
- 各区块滚动进入时淡入上浮（IntersectionObserver，带 2.5s 兜底强制显示）
- AI 解析文字打字机效果；追问气泡依次出现；FSRS 时间轴逐点亮起；批注笔迹描边动画
- 数据指标进入视口时数字滚动（带 3s 兜底）
- 已适配 `prefers-reduced-motion`（用户开启"减少动态效果"时全部动画关闭）
