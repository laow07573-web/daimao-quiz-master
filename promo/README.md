# 猫卷 · 功能展示页

面向推广的静态展示页：用动画分区展示 App 各项功能，每个功能区标明所用技术与实现方式。

## 打开方式

- **本地预览**：直接双击 `index.html`（部分浏览器对本地文件限制较严，建议用本地服务器）
- **本地服务器**：
  ```bash
  cd 项目根目录
  python -m http.server 8899
  # 浏览器打开 http://127.0.0.1:8899/promo/index.html
  ```

## 部署

整个 `promo/` 文件夹丢到任意静态托管即可（GitHub Pages / Gitee Pages / Vercel / 对象存储 / 自己的服务器）。
无需构建步骤，无外部依赖。

## 需要改的地方

1. **下载链接**：`index.html` 里搜 `id="dl-apk"` 与 `id="dl-win"`，把 `href` 改成实际下载地址（当前指向 `../dist/` 下的交付物）
2. **截图更新**：替换 `assets/` 下的图片（建议保持同名，或同步修改 HTML 里的 `assets/xxx.webp`）
3. **文案**：正文直接改 `index.html`，无构建步骤

## 截图显示规范（重要）

展示截图必须**完整、不裁切、清晰**。本页已按以下规则处理，替换素材时请沿用：

1. **画框比例 = 截图真实比例**：每个 `.phone` / `.window` 的 `--ar` 必须与其中图片的真实宽高比一致，否则会留白或裁切

   | 截图来源 | 真实比例 | `--ar` 取值 |
   |---|---|---|
   | `1116×2480` 系列（解析/追问/错题本/主题等） | 0.45 | `1116/2480` |
   | `1080×1920` 系列（导入/题库/深色首页） | 0.5625 | `1080/1920` |
   | `1600×2560` 系列（首页/答题卡/批注/统计） | 0.625 | `1600/2560` |
   | 宽屏 `1280×800` | 1.6 | `1280/800` |
   | 宽屏 `1600×1000` | 1.6 | `1600/1000` |

2. **图片填充用 `object-fit: contain`**（完整显示）——不要改回 `cover`，否则会裁掉两侧内容
3. **比例设在「屏幕内框」上**（`.phone .scr` / `.window .wbody`），**不是外框** —— 外框含 padding 与标题栏，设在外框会让内框比例偏移、产生留白
4. **不要加假刘海** —— 会盖住截图自带的顶部状态栏
5. **素材分辨率**：竖屏截图统一缩到 900px 宽（最大手机框 368 CSS px，2× 屏需 736px，900px 有余量），格式 WebP quality 92

## 动画说明

- Hero 与「三种模式」的手机截图自动轮播（2.4–2.6s/张）
- 各区块滚动进入时淡入上浮（IntersectionObserver，带 2.5s 兜底强制显示）
- AI 解析文字打字机效果；追问气泡依次出现；FSRS 时间轴逐点亮起；批注笔迹描边动画
- 数据指标进入视口时数字滚动（带 3s 兜底）
- 已适配 `prefers-reduced-motion`（用户开启"减少动态效果"时全部动画关闭）
