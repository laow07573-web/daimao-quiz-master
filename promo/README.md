# 猫卷 · 功能展示页

面向推广的静态展示页：用动画分区展示 App 各项功能，每个功能区标明所用技术与实现方式。

## 界面渲染方式：纯代码矢量重绘（无位图）

页面里的 App 界面**不是截图**，而是用 HTML/CSS **按真实设计规格重绘**的矢量界面：

- **任意缩放都清晰** —— 文字、图标、图形都是矢量，放大到 4K 也不糊
- **永不裁切** —— 画框比例即设计稿比例（390:867），内容由 `--s` 缩放系数精确适配，零留白零裁切
- **体积极小** —— 整个页面 404KB（此前用截图方案为 1.2MB）
- **可以做真实动效** —— AI 解析逐字打出、追问气泡依次出现、内容缓慢滚动浏览、界面自动轮播

已重绘 6 个界面（`<template>` 模板）：`tpl-home` 首页 / `tpl-quiz` 答题页 / `tpl-ai` AI解析+追问 / `tpl-stats` 统计页 / `tpl-errbook` 错题本 / `tpl-import` 导入页 / `tpl-home-dark` 深色首页。

配色取自 `lib/services/theme_service.dart` 的真实色值（导航栏 `#1E3A5F`、正确绿 `#DCFCE7`、错误红 `#FEE2E2` 等），已用浏览器实测逐项校验一致。

### 如何新增/修改一个界面

1. 在页面中新增一个 `<template id="tpl-xxx">`，最外层为 `<div class="mscr" data-t="brand"><div class="mroot">…</div></div>`
2. 在某个画框的 `.scr` 上标注 `data-mock="xxx"`（单个）或 `data-mocks="xxx,yyy"`（轮播）
3. 画框的 `--ar` 统一用 `390/867`；组件类名见 CSS 里 `/* 重绘 App 界面 */` 段落（`.mapp/.mbody/.mcard/.mopt/.mbub/.mcal/.mchart` 等）
4. 月历用 `.mcal[data-y=年][data-m=月][data-today=日][data-h=逗号分隔的热力等级0-3]`；趋势图用 `.mchart[data-d=逗号分隔的数据]`，二者由 JS 自动生成

  ```bash
  cd 项目根目录
  python -m http.server 8899
  # 浏览器打开 http://127.0.0.1:8899/promo/index.html
  ```

## 需要改的地方

1. **下载链接**：`index.html` 里搜 `id="dl-apk"` 与 `id="dl-win"`，把 `href` 改成实际下载地址（当前指向 `../dist/` 下的交付物）
2. **界面内容**：改对应的 `<template id="tpl-*">` 里的 HTML（文案、数字、题目等）
3. **仍然使用真实截图的 4 处**：手写批注（`annot_*.webp`，笔迹用照片更真实）、题库管理、多端适配宽屏（`wide_*.webp`）、我的页面 —— 替换 `assets/` 下同名文件即可，比例规则：竖屏画框 `--ar` 需等于截图真实比例，图片填充保持 `object-fit: contain`

## 截图显示规范（仅适用于上面仍用位图的 4 处）

1. **画框比例 = 截图真实比例**，否则会留白或裁切。对照：`1116×2480→1116/2480`、`1080×1920→1080/1920`、`1600×2560→1600/2560`、`1280×800→1280/800`
2. **图片填充用 `object-fit: contain`**，不要改成 `cover`（会裁掉两侧）
3. **比例设在「屏幕内框」上**（`.phone .scr` / `.window .wbody`），不是外框
4. **不要加假刘海** —— 会盖住截图自带的顶部状态栏

## 动画说明

- **界面轮播**：Hero（首页→答题→AI解析→统计）与「三种模式」区块的矢量界面自动切换（3s/张）；切换时触发对应界面的内部动效
- **内容滚动浏览**：首页与统计页界面会缓慢上下平移，展示画框之外的更多内容（模拟真人浏览）
- **AI 解析打字机**：`data-type` 属性里的文本逐字打出，带光标闪烁
- **追问气泡**：依次淡入上浮
- **月历与趋势图**：由 `data-y/data-m/data-h`、`data-d` 属性实时生成（矢量绘制）
- 各区块滚动进入时淡入上浮（IntersectionObserver，带 2.5s 兜底强制显示）
- FSRS 时间轴逐点亮起；批注笔迹描边动画
- 数据指标进入视口时数字滚动（带 3s 兜底）
- 已适配 `prefers-reduced-motion`（用户开启"减少动态效果"时全部动画关闭）
